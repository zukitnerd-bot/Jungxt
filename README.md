# JUNGXT

The Urban Dictionary for texting. A dictionary of autocorrect casualties, sleepy-texting slang, and forehead-typing classics.

Live site: https://muse.ai/s/jungxt-by6xd2xjqxzxzhxd

## What's inside

- 24 entries and counting — from classics like "ducking" to original canon like "Sven"
- Word of the Day, live search, category filters
- Upvote entries into the Hall of Fame
- "Coin a jungxt" — add your own garbled terms

## Run it

It's a single self-contained HTML file. Open `index.html` in any browser. No build step, no dependencies.

## API

`api/` holds the Jungxt API — every definition as JSON. `python3 api/server.py`, no dependencies. See `api/README.md`. Free for non-commercial use; commercial licensing: licensing@jungxt.com.
